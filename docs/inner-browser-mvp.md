 🌍 浏览器

### navigate_page — 导航/后退/前进/刷新

| 参数          | 类型    | 必需 | 描述                                            |
| ------------- | ------- | ---- | ----------------------------------------------- |
| `type`        | string  | ✅   | 导航类型：`url` / `back` / `forward` / `reload` |
| `url`         | string  | ❌   | 目标 URL（仅 type=url）                         |
| `timeout`     | integer | ❌   | 最大等待时间（毫秒，默认 30000）                |
| `ignoreCache` | boolean | ❌   | 刷新时是否忽略缓存                              |

### take_snapshot — 获取页面可访问性树快照

| 参数       | 类型    | 必需 | 描述                                       |
| ---------- | ------- | ---- | ------------------------------------------ |
| `verbose`  | boolean | ❌   | 是否包含完整的可访问性树信息（默认 false） |
| `filePath` | string  | ❌   | 保存快照的文件路径                         |

### take_screenshot — 页面/元素截图

| 参数       | 类型    | 必需 | 描述                                      |
| ---------- | ------- | ---- | ----------------------------------------- |
| `format`   | string  | ❌   | 格式：`png` / `jpeg` / `webp`（默认 png） |
| `quality`  | number  | ❌   | JPEG/WebP 质量（0-100）                   |
| `uid`      | string  | ❌   | 元素 uid，省略则截取整个页面              |
| `fullPage` | boolean | ❌   | 是否截取整个滚动页面（与 uid 互斥）       |
| `filePath` | string  | ❌   | 保存截图的文件路径                        |

### click — 单击/双击元素

| 参数              | 类型    | 必需 | 描述                               |
| ----------------- | ------- | ---- | ---------------------------------- |
| `uid`             | string  | ✅   | 页面快照中的元素 uid               |
| `dblClick`        | boolean | ❌   | 是否双击（默认 false）             |
| `includeSnapshot` | boolean | ❌   | 是否在响应中包含快照（默认 false） |

### hover — 悬停元素

| 参数              | 类型    | 必需 | 描述                 |
| ----------------- | ------- | ---- | -------------------- |
| `uid`             | string  | ✅   | 页面快照中的元素 uid |
| `includeSnapshot` | boolean | ❌   | 是否在响应中包含快照 |

### fill — 输入文本/选择下拉选项

| 参数              | 类型    | 必需 | 描述                       |
| ----------------- | ------- | ---- | -------------------------- |
| `uid`             | string  | ✅   | 页面快照中的元素 uid       |
| `value`           | string  | ✅   | 要填充的文本或选择的选项值 |
| `includeSnapshot` | boolean | ❌   | 是否在响应中包含快照       |

### fill_form — 批量填充多个表单元素

| 参数              | 类型    | 必需 | 描述                                           |
| ----------------- | ------- | ---- | ---------------------------------------------- |
| `elements`        | array   | ✅   | 元素列表，每项含 `uid`(string)+`value`(string) |
| `includeSnapshot` | boolean | ❌   | 是否在响应中包含快照                           |

### drag — 拖拽元素到目标元素

| 参数              | 类型    | 必需 | 描述                 |
| ----------------- | ------- | ---- | -------------------- |
| `from_uid`        | string  | ✅   | 被拖拽元素的 uid     |
| `to_uid`          | string  | ✅   | 目标元素的 uid       |
| `includeSnapshot` | boolean | ❌   | 是否在响应中包含快照 |

### upload_file — 上传文件

| 参数              | 类型    | 必需 | 描述                     |
| ----------------- | ------- | ---- | ------------------------ |
| `uid`             | string  | ✅   | 文件输入或触发元素的 uid |
| `filePath`        | string  | ✅   | 要上传的文件的本地路径   |
| `includeSnapshot` | boolean | ❌   | 是否在响应中包含快照     |

### press_key — 按键或组合键

| 参数              | 类型    | 必需 | 描述                                                     |
| ----------------- | ------- | ---- | -------------------------------------------------------- |
| `key`             | string  | ✅   | 按键或组合键，如 `Enter`、`Control+A`、`Control+Shift+R` |
| `includeSnapshot` | boolean | ❌   | 是否在响应中包含快照                                     |

### type_text — 键盘输入文本

| 参数        | 类型   | 必需 | 描述                              |
| ----------- | ------ | ---- | --------------------------------- |
| `text`      | string | ✅   | 要输入的文本                      |
| `submitKey` | string | ❌   | 输入后按下的键，如 `Enter`、`Tab` |

### evaluate_script — 在页面中执行 JavaScript

| 参数           | 类型   | 必需 | 描述                                                     |
| -------------- | ------ | ---- | -------------------------------------------------------- |
| `function`     | string | ✅   | JS 函数声明，如 `() => { return document.title }`        |
| `args`         | array  | ❌   | 传递给函数的元素 uid 列表                                |
| `dialogAction` | string | ❌   | 弹窗处理：`accept` / `dismiss` / 提示文本（默认 accept） |

### wait_for — 等待文本出现

| 参数      | 类型         | 必需 | 描述                                     |
| --------- | ------------ | ---- | ---------------------------------------- |
| `text`    | string/array | ✅   | 要等待的文本（可传数组，任一出现即返回） |
| `timeout` | integer      | ❌   | 最大等待时间（毫秒，默认 30000）         |

### handle_dialog — 处理弹窗

| 参数         | 类型   | 必需 | 描述                       |
| ------------ | ------ | ---- | -------------------------- |
| `action`     | string | ✅   | 操作：`accept` / `dismiss` |
| `promptText` | string | ❌   | 提示框输入文本             |

### list_pages — 列出所有打开的标签页

无参数

### select_page — 切换标签页

| 参数     | 类型   | 必需 | 描述            |
| -------- | ------ | ---- | --------------- |
| `pageId` | number | ✅   | 要选择的页面 ID |

### resize_page — 调整窗口大小

| 参数     | 类型   | 必需 | 描述     |
| -------- | ------ | ---- | -------- |
| `width`  | number | ✅   | 页面宽度 |
| `height` | number | ✅   | 页面高度 |

### emulate — 模拟深色模式/UA

| 参数          | 类型   | 必需 | 描述                              |
| ------------- | ------ | ---- | --------------------------------- |
| `colorScheme` | string | ❌   | `dark` / `light` / `auto`         |
| `userAgent`   | string | ❌   | 模拟的 User-Agent（空字符串清除） |

### show_browser — 显示浏览器面板

无参数

### hide_browser — 隐藏浏览器面板

无参数

### create_page — 创建新标签页（此工具未在 schema 中定义，源自文档）

| 参数  | 类型   | 必需 | 描述       |
| ----- | ------ | ---- | ---------- |
| `url` | string | ❌   | 加载的 URL |

### close_page — 关闭标签页

| 参数     | 类型   | 必需 | 描述            |
| -------- | ------ | ---- | --------------- |
| `pageId` | number | ✅   | 要关闭的页面 ID |
